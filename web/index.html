YouTube는 E/R/D/F/Y/U가 플레이어에 바로 연결됩니다. CHZZK·SOOP은 위 컷 기준 시각으로 E/R/D/F를 바로 쓰고, Y/U를 누르면 플레이어에서 바꿀 위치를 안내합니다. W로 도우미를 연결하면 같은 버튼이 실제 영상과 동기화됩니다.

영상 준비 도우미만 연결하면 바로 이어집니다

컷 선택과 편집은 계속 이 웹사이트에서 합니다. 도우미는 선택한 영상 구간만 이 PC에 준비하며 별도 작업 창을 열지 않습니다.

1
Linux 도우미 받기Debian/Ubuntu 또는 Arch Linux x64용 파일을 고릅니다.
2
다운로드 후 설치·실행패키지를 설치하고 도우미를 한 번 실행합니다.
3
이 화면에서 연결 확인도우미 실행을 자동 감지하고, ‘설치 후 연결 확인’ 한 번으로 이 브라우저를 등록합니다.

현재 공개 테스트는 Debian/Ubuntu·Arch Linux x64를 지원합니다.

다운로드를 누르면 이 화면에 다음 행동을 계속 안내합니다. 실제 파일 진행률은 브라우저의 다운로드 표시에서 확인할 수 있습니다.
