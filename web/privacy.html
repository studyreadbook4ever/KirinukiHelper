Kirinuki 운영 서버

Kirinuki는 정적 웹 앱입니다. 회원 계정·로그인이나 서버 프로젝트 데이터베이스가 없으며, 원본 VOD 주소·선택한 컷·자막·편집 프로젝트와 원본 영상 파일을 Kirinuki 애플리케이션 기록으로 업로드하거나 보관하는 기능을 두지 않습니다.

웹 요청은 사이트 전달과 보안을 위해 Cloudflare와 Kirinuki 원본 서버를 통과합니다. 이 과정에서는 IP 주소, 요청 시각, 요청 경로, 브라우저·네트워크 정보 같은 통신 정보가 처리될 수 있습니다. 따라서 Kirinuki는 이 전달 계층의 정보 처리가 0이라고 단정하지 않습니다.

VOD 주소와 주소창 정리

주소에 source가 포함된 링크로 들어오면 Kirinuki는 그 값을 원본 VOD 입력칸에 한 번 반영하고, 페이지를 다시 불러오지 않은 채 주소창을 /로 즉시 정리합니다. 그 뒤에 광고 스크립트를 시작합니다. 입력칸의 값과 편집 흐름은 그대로 유지됩니다.

#source=… 형태의 fragment는 최초 HTTP 요청에 포함되지 않습니다. 기존 ?source=… 링크도 계속 지원하지만, query는 최초 페이지 요청 때 전달 인프라에 도달한 뒤 브라우저에서 제거된다는 차이가 있습니다.

브라우저와 이 PC에서 처리하는 정보

저장한 편집, 복구본, 컷과 자막은 브라우저 저장소에 남습니다. 영상 준비 도우미는 사용자가 선택한 구간을 이 PC로 받아 웹 편집기에 제공하며, 준비한 영상과 캐시는 이 PC에 남습니다. 이 데이터는 Kirinuki 운영 서버의 프로젝트 데이터베이스로 전송되지 않습니다.

웹사이트의 저장된 편집 삭제·작업 끝내기 기능, 브라우저의 사이트 데이터 삭제, 운영체제의 도우미 제거 기능으로 각 로컬 데이터를 정리할 수 있습니다.
