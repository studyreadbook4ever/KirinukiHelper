# Kirinuki로 자막 편집하기

사용자와 같은 데스크톱 브라우저에서 원음을 확인하고, 편집 타임라인에 자막을 넣고, 결과물을 PC에 저장하는 방법입니다. 한국어 화면의 버튼 이름과 언어 설정에 관계없이 쓸 수 있는 요소 ID를 함께 적었습니다. [Kirinuki 열기](https://kirinuki.eff0rtchung.kr/)

## 시작할 작업 고르기

- 이미 편집기가 열려 있으면 프로젝트 이름과 작업공간부터 확인합니다. 쇼츠는 **쇼츠 편집기**에서 열고, 여러 개라면 현재 작업 선택기(`#short-workspace-select`)에서 이름을 대조합니다. 본편과 각 쇼츠는 독립된 자막과 시간표를 가집니다.
- 새 편집이면 CHZZK·YouTube·SOOP의 공개 완료 VOD 주소(`#source-url`)와 프로젝트 이름을 입력합니다. 사용자가 고른 구간을 원본 플레이어에서 재생하며 **시작 캡처**(`E`), **끝 캡처**(`R`)로 표시합니다. 구간 목록의 시작·끝과 재생 순서를 확인합니다.
- 새 작업, 저장본 열기, 복구 때의 **권리 확인**은 이번 원본과 사용 목적에 대해 사용자가 직접 작성합니다. 확인이 끝나면 **편집기 열기**를 누릅니다. 영상 준비 도우미나 파일 접근 권한을 요청하는 시스템 창은 사용자가 조작합니다. 권한 있는 파일을 사용할 때는 **내 파일 직접 연결**(`#pick-media`)에서 해당 파일을 고릅니다.
- 자막 작업에서는 사용자가 정한 컷 경계, 순서, 영상 구도와 음성 믹스를 유지합니다. 기존 작업을 이어받으면 **지금 저장**(`#create-local-draft`)으로 편집 전 버전을 남길 수 있습니다.

## 다른 편집 도구가 필요한 경우

| 사용자 요청 | 화면에서 할 일 |
| --- | --- |
| 여러 컷을 골라 나중에 계속하기 | 시작 화면에서 `T`로 다음 구간을 추가합니다. **현재 컷 백업**으로 구간과 메모를 저장하고, 다음 작업에서는 **백업 파일 불러오기**로 엽니다. |
| 컷이나 영상 구도 조정하기 | 본편 타임라인의 **컷·원본 관리**에서 대상 컷을 확인합니다. 화면 일부를 잘라낼 때는 **영상 영역 자르기**에서 미리보기를 확인한 뒤 적용합니다. |
| 이미지를 넣거나 음성을 조정하기 | 타임라인에서 사용할 위치로 이동해 **이미지 붙여넣기** 또는 **현재 위치 음성 설정**을 선택합니다. 오른쪽의 **이미지**·**음성** 탭에서 대상과 적용 구간을 확인합니다. |
| 저장한 시점으로 돌아가기 | **저장·복구본**에서 작업 이름과 시각을 대조한 뒤 필요한 버전을 선택합니다. |

## 들리는 말에 자막 붙이기

1. **자막**(`#caption-mode-tab`)을 열고 편집 미리보기를 재생합니다. 사용할 근거는 접근 가능한 원음, 사용자가 제공한 전사·가사, 인명·용어 표기입니다. 브라우저를 클릭할 수 있어도 에이전트가 소리를 들을 수 있는지는 별개입니다. 원음을 들을 수 없다면 사용자가 제공한 시각 있는 전사로 입력하고, 음성과의 일치 여부는 미확인으로 기록합니다. 전사도 없으면 빈 타이밍 초벌까지 진행한 뒤 필요한 구간의 원음이나 문구를 요청합니다.
2. 한두 줄이라면 재생 헤드를 첫 음절로 옮겨 **+ 직접 추가**(`#add-cue-top`)를 누릅니다. 구간이 많으면 **자막 위치 자동으로 넣기**(`#generate-captions`)를 사용합니다. AudSeg는 이 브라우저에서 음량 변화를 분석해 최대 4초짜리 빈 자막 칸을 제안합니다. 음악·박수·효과음도 감지되므로 각 칸에서 실제 발화를 확인합니다.
3. 타임라인에서 자막 블록을 선택하고 **선택 자막**의 본문(`#cue-text`)에 들은 문구를 입력합니다. 입력 중 `Ctrl+Enter`(Mac은 `⌘+Enter`)로 같은 레인의 다음 자막에 이어 쓰고, `Shift`를 함께 누르면 이전 자막으로 갑니다. 한국어 입력기에서는 마지막 음절 조합을 마친 뒤 이동합니다. 입력칸 밖에서는 `J`·`K`가 같은 레인의 이전·다음 자막으로 이동합니다.
4. **시작**(`#cue-start`)과 **끝**(`#cue-end`)에 편집 타임라인 시각을 입력하고 포커스를 옮겨 적용합니다. 타임라인 양끝 손잡이로도 조정할 수 있습니다. 현재 컷의 시작·끝과 실제 발음에 맞춰 다듬습니다. 예를 들어 원본 01:20에 시작하는 컷을 본편 첫 장면으로 쓰고 발화가 원본 01:22.300에 시작했다면, 자막 시작은 편집 시각 `00:02.300`입니다. 앞에 다른 활성 컷이 있으면 그 길이도 포함합니다.
5. 첫 음절 직전부터 끝 음절 뒤까지 다시 재생합니다. 긴 문장은 자연스럽게 읽히는 단위로 나누고, 동시에 말하는 화자나 원문·번역을 함께 표시할 때는 별도 자막 레인과 화면 위치를 사용합니다. 불분명한 단어와 화자명은 추측으로 채우지 말고 해당 컷과 시각을 사용자 검수 목록에 남깁니다. 노래 가사는 승인된 가사와 실제로 들리는 반복 구절을 대조합니다. **에이전트로 자막 넣기**는 1/60초 단위 노래 싱크를 위한 작업 지침을 보여 줍니다. 버튼을 여는 것만으로 전사가 실행되지는 않습니다.

## 화면에서 검수하기

- **전체**(`#cue-list-tab`)의 검색과 **빈 자막**, **검수 필요한 자막** 필터로 누락과 미확인 항목을 점검합니다. **다음 검수 자막**(`#next-review-cue`)은 여러 레인을 시간순으로 순회하므로 같은 항목으로 돌아오면 남은 건수를 확인합니다. 목록에서 이동한 것만으로 검수가 완료되지는 않습니다.
- **공통 스타일**(`#cue-style-tab`)에서 글꼴(`#caption-font-family`)을 고르면 현재 작업공간의 모든 자막에 적용됩니다. 미리보기에서 줄바꿈, 색 대비, 다른 자막과의 가림을 확인하고 쇼츠는 세로 화면에서도 확인합니다. **자막 스타일 비교**는 위치·크기·색·배경을 비교하는 화면입니다. 문구 확인은 **선택 자막**이나 **전체**에서 합니다.
- 처음부터 끝까지 재생하며 컷 전환 직전·직후, 겹치는 대사, 첫 줄과 마지막 줄의 싱크를 확인합니다. 제공된 원본·전사·가사를 외부 서비스에 보내야 하는 방식은 사용자가 전송 대상과 범위를 명시적으로 승인한 경우에만 사용합니다. 웹 편집만으로는 그 자료를 외부에 보낼 필요가 없습니다.

## PC에 저장하기

- **영상 내보내기**(`#export-video`)에서 제목(`#export-file-title`)을 정합니다. 자막 파일만 요청받았으면 **자막만 받기 (.srt)**(`#download-export-captions`)를 누릅니다. 본문이 있는 활성 컷의 자막을 편집 시각순으로 담은 UTF-8 `.ko.srt`가 내려받아집니다. 빈 칸은 생략됩니다. 영상 렌더링이나 원본 파일 재연결 없이도 받을 수 있습니다.
- 자막이 보이는 완성 영상이 필요하면 **저장 위치 선택하고 내보내기**를 눌러 폴더를 선택합니다. 완료 화면에서 영상·편집 복원 JSON·자막이 있는 경우 SRT의 실제 파일명을 확인합니다. SRT에는 문구와 시각이 담기고, 글꼴·위치·색은 렌더한 영상에서 확인할 수 있습니다.
- 저장한 SRT의 첫 줄과 마지막 줄을 결과 영상의 해당 시각과 대조합니다. 에이전트가 내려받은 파일을 열거나 재생할 수 없다면 확인한 화면과 사용자가 확인할 항목을 구분해 전달합니다. 마무리할 때는 해당 작업공간, 실제로 저장한 파일, 검수가 남은 컷의 시각을 알려 줍니다. 이어 편집할 작업은 **지금 저장**으로 남깁니다.
