영상 편집은 Kirinuki 앱에서 이어집니다

이 페이지는 앱을 시작하거나 설치하는 곳입니다. 원본 선택부터 내보내기까지는 내 컴퓨터에서 실행되는 Kirinuki 앱 안에서 처리됩니다.

Kirinuki 앱에서 열기 설치 방법 보기

앱이 열리지 않았다면 설치 방법을 확인한 뒤 Linux 컴퓨터의 앱 메뉴에서 Kirinuki를 실행하세요. 모바일에서는 편집기를 열 수 없습니다.

설치 전에 확인

Linux PC에 Node.js 22.13.0 이상과 npm, Chromium 120 이상, Python 3.11 이상, FFmpeg와 ffprobe가 필요합니다.

Whisper 자막을 선택할 때만 CMake, tar와 C++ 컴파일러(g++ 또는 clang++)가 추가로 필요합니다.

이 사이트는 로그인, 사용자 세션, 분석 도구 없이 정적 파일만 제공합니다. 사용기록과 개인정보를 수집하지 않습니다.
